# 降雨、高温与果园作业安全要点（演示资料）

**资料类型**：果园安全与天气响应参考  
**来源单位**：榄园知行演示资料库  
**建议标签**：天气、降雨、高温、雷雨、作业安全、演示样例  
**使用说明**：天气数据必须以系统显示的数据来源、更新时间和缓存状态为准。本文件仅提供实训场景的通用检查清单。

## 一、天气信息的正确使用方式

天气信息可帮助安排巡园、灌溉、施肥和采收，但不能替代现场观察。查看天气时，应关注数据来源、更新时间、当前天气、温度、风力以及未来数日的降雨趋势。若系统提示天气接口调用失败或展示的是缓存/演示数据，应如实说明，不能把它当作实时事实使用。

## 二、降雨前后的检查清单

### 降雨前

- 清理或检查排水沟，避免落叶、杂草和杂物影响排水；
- 检查支撑、覆盖物、工具和电气设施的稳固性；
- 核对计划中的灌溉和施肥任务，必要时提请教师调整；
- 对低洼地、易积水区和已有异常植株做好标记。

### 降雨后

- 先观察积水、沟渠、道路湿滑和土壤通气情况；
- 记录落果、折枝、叶片破损或病虫害迹象是否增加；
- 在土壤湿度较高、作业道路湿滑时，避免不必要的机械作业；
- 如需恢复灌溉或施肥计划，应结合现场墒情和指导教师意见重新判断。

## 三、高温、雷雨和大风天气

高温时，学生应注意防暑、防晒、饮水和作业时段安排，避免长时间连续暴露。雷雨、大风、强对流等天气下，不应在果园内进行登高修剪、使用电气设备、靠近高大树体或金属设施等高风险作业。发现天气变化快、雷电预警或能见度显著下降时，应优先撤离到安全区域并报告教师。

## 四、智能体回答的安全边界

当用户询问“是否今天必须灌溉”“是否可以立即施肥”时，智能体应结合天气工具和知识资料给出条件性建议，例如提示检查土壤墒情、排水和任务优先级；不应在缺乏现场数据时给出绝对命令。当工具失败时，回答应明确失败原因或数据时效，建议用户先核对现场与指导教师意见。

## 五、建议提问语句

- “未来两天有大雨，幼果期是否需要暂缓滴灌？”
- “雷雨天气前后，巡园应该重点检查哪些部位？”
- “高温天气下，学生进行果园实训需要注意什么？”
