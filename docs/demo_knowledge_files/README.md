# 榄园知行演示知识库文件

本目录包含用于“榄园知行”演示的 5 份示例知识资料。它们仅用于展示系统的文件上传、解析、切分、向量检索、来源引用和 Agent 问答流程，**当前未上传至系统，也未写入数据库**。

## 文件清单

1. `01_幼果膨大期水肥管理演示资料.md`
2. `02_降雨高温与果园作业安全演示资料.md`
3. `03_橄榄异常观察与上报要点.txt`
4. `04_农事用量计算与安全边界演示资料.md`
5. `05_采收贮运与实训记录演示资料.md`

## 演示建议

- 在知识库页面逐个上传上述文件，填写来源单位“榄园知行演示资料库”、适用地区和物候期标签。
- 等待处理状态变为“成功”后，演示提问并展示返回的资料名称、片段与来源。
- 建议提问：

  - “幼果膨大期遇到连续降雨，应先检查什么？”
  - “高温和雷雨天气下，学生巡园有哪些安全注意事项？”
  - “发现落果和叶片异常时，需要记录哪些信息？”

## 使用边界

资料中的内容是面向竞赛演示的通用教学样例，不构成针对某一果园、品种、农药产品或病虫害的生产处方。实际灌溉、施肥、植保与采收作业，应以当地技术规程、产品标签、现场条件和指导教师意见为准。
