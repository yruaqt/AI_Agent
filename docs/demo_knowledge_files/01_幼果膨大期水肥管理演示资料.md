# 中国橄榄幼果膨大期水肥管理要点（演示资料）

**资料类型**：实训教学参考  
**来源单位**：榄园知行演示资料库  
**适用对象**：中国橄榄（青橄榄）校园实训果园  
**建议标签**：幼果膨大期、水肥管理、滴灌、演示样例  
**使用说明**：本资料用于知识库检索与来源引用演示，不替代当地农艺师或指导教师的现场方案。

## 一、阶段特点

幼果膨大期是果实体积和干物质积累的重要阶段。管理时既要避免土壤长期缺水影响果实发育，也要避免连续降雨后仍按固定计划灌水或追肥。校园实训中，应把“当前物候期、土壤墒情、近期降雨、排水条件和树体长势”作为共同判断依据，不能只依据日期或单一经验安排作业。

## 二、灌溉观察要点

1. 灌溉前先查看滴灌系统、土壤表层与根系主要分布层的湿润情况，并记录最近降雨。
2. 如未来一两天可能出现明显降雨，应先核实天气数据与排水条件，再决定是否暂缓灌水；不要把预报降雨直接等同于根区已获得有效水分。
3. 连续降雨后，应优先检查园区低洼处积水、沟渠排水、根际通气和落果情况。排水不畅时，重点是排涝和巡查，而不是追加灌水。
4. 高温、干热风或滴灌压力异常时，应及时向指导教师反馈。灌溉量需要按株数、树龄、土壤条件和当地规程确定，可使用系统计算器核算总水量。

## 三、施肥管理要点

1. 施肥前应明确肥料种类、目标用量、土壤和树体状况，并核对学校实训计划。
2. 大雨前后不宜机械照搬原计划追肥。雨前追施可能增加流失风险，雨后应先评估土壤湿度、排水和施肥位置。
3. 施肥应与灌溉、修剪、病虫害观察等工作统筹安排。发现叶色异常、落果增多或长势明显偏弱时，应先记录现象并进行原因排查，不应直接将其归因为缺肥。
4. 涉及较大面积施肥、配方调整或新产品试用时，须由指导教师确认，并保留肥料名称、批次、用量和作业日期。

## 四、实训记录模板

建议学生在作业后记录以下内容：

- 果园名称、日期、当前物候期；
- 最近天气与降雨情况；
- 土壤表面和排水沟观察情况；
- 灌溉方式、计划用水量、实际作业时间；
- 肥料名称、单株或单位面积用量、总量；
- 异常现象、照片编号和需教师确认的问题。

## 五、安全提示

本资料不提供农药推荐和具体施肥处方。雷雨、大风、高温等危险天气下，学生不应冒险进入果园作业；涉及用电、机械、农药、较大用量施肥或登高修剪时，应遵守学校安全制度并由教师组织。
