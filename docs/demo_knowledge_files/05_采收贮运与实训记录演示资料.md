# 橄榄采收、贮运与实训记录基础（演示资料）

**资料类型**：采收实训与记录参考  
**来源单位**：榄园知行演示资料库  
**建议标签**：成熟期、采收、贮运、实训记录、演示样例  
**使用说明**：本资料为演示系统在成熟期检索与生成任务的示例材料。具体采收标准应以学校品种特性、用途和指导教师要求为准。

## 一、采收前准备

采收前应确认果园、品种、预期用途和成熟度要求，检查天气、人员分组、采收容器、运输路线和安全防护用品。雨天或果面潮湿时，应结合现场条件和教师安排判断是否适宜作业，避免因路滑、枝条湿滑或果实损伤增加安全和品质风险。

## 二、现场操作要点

1. 轻拿轻放，尽量减少挤压、碰撞和混入枝叶、泥沙等杂质；
2. 对不同地块、不同成熟度或不同用途的果实做好分装和标记；
3. 发现病果、虫果、机械伤果或异常果时，应单独记录和处理；
4. 采收过程中关注登高、工具使用、道路通行和人员协作安全；
5. 采收结束后清点容器、记录重量或抽样数据，并按要求送往暂存或处理地点。

## 三、贮运与质量记录

采后应减少长时间日晒、积压和高温暴露，尽快完成分级、转运或暂存。实训记录可包括采收日期、果园与地块、天气、参与人员、采收量、抽样株数、果实外观、异常比例、运输方式及教师评语。若使用系统产量估算工具，应同时保存抽样方法和估算条件。

## 四、与智能体任务闭环的关系

系统可根据当前物候期、近期天气、知识库资料和果园档案生成“采收前检查”“采后分级与记录”等结构化任务。任务由教师审核后分配给学生；学生执行后填写现场数据和异常情况，形成后续教学复盘可查询的记录。智能体生成的建议是任务草案，最终作业安排以教师审核为准。
