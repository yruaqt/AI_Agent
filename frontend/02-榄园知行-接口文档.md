# 榄园知行——橄榄果园智能管理与农事决策系统接口文档

## 1. 文档说明

本文定义 Vue 3 前端与 Spring Boot 3 后端之间的 REST/SSE 接口，同时说明 LangChain4j Agent 内部工具接口。开发过程中以后端生成的 OpenAPI 文档为最终可执行契约；若字段变更，必须同步更新本文和前端类型定义。

## 2. 基础约定

### 2.1 基础地址

```text
开发环境：http://localhost:8080/api/v1
接口文档：http://localhost:8080/swagger-ui/index.html
OpenAPI：http://localhost:8080/v3/api-docs
```

### 2.2 数据格式

- 默认请求与响应格式：`application/json;charset=UTF-8`
- 文件上传：`multipart/form-data`
- Agent 流式响应：`text/event-stream;charset=UTF-8`
- 日期：`yyyy-MM-dd`
- 时间：ISO 8601，例如 `2026-07-15T10:30:00+08:00`
- 数据库主键和前端 ID 均使用 64 位整数；前端可按字符串保存，避免精度问题。

### 2.3 认证方式

除登录接口外，请求头携带 JWT：

```http
Authorization: Bearer <access_token>
```

API Key 仅保存在后端环境变量中，前端不得上传、读取或缓存模型平台密钥。

### 2.4 统一响应

成功响应：

```json
{
  "code": 0,
  "message": "success",
  "data": {},
  "requestId": "01J2XYZ...",
  "timestamp": "2026-07-15T10:30:00+08:00"
}
```

失败响应：

```json
{
  "code": 40001,
  "message": "请求参数不正确",
  "data": null,
  "requestId": "01J2XYZ...",
  "timestamp": "2026-07-15T10:30:00+08:00"
}
```

分页响应中的 `data`：

```json
{
  "items": [],
  "page": 1,
  "pageSize": 20,
  "total": 0
}
```

### 2.5 通用错误码

| HTTP状态 | 业务码 | 含义 |
| --- | --- | --- |
| 400 | 40001 | 请求参数错误 |
| 401 | 40101 | 未登录或令牌失效 |
| 403 | 40301 | 无操作权限 |
| 404 | 40401 | 资源不存在 |
| 409 | 40901 | 数据状态冲突或重复 |
| 413 | 41301 | 上传文件过大 |
| 429 | 42901 | 请求过于频繁 |
| 500 | 50001 | 系统内部错误 |
| 502 | 50201 | 模型服务调用失败 |
| 502 | 50202 | Embedding 服务调用失败 |
| 502 | 50203 | 天气服务调用失败 |
| 504 | 50401 | 外部服务超时 |

```json
    }
  ],
  "model": "qwen-plus",
  "finishReason": "STOP"
}
```

### 7.5 发送消息（SSE流式接口）

```http
POST /chat/sessions/{sessionId}/messages/stream
Accept: text/event-stream
Content-Type: application/json
```

请求体与非流式接口一致。Vue 前端使用 `fetch` 读取响应流，不使用只能发 GET 的原生 `EventSource`。

事件定义：

```text
event: start
data: {"messageId":"3102"}

event: tool_call
data: {"name":"queryOrchardWeather","status":"RUNNING"}

event: tool_result
data: {"name":"queryOrchardWeather","status":"SUCCESS","summary":"已查询未来3天天气"}

event: delta
data: {"content":"根据未来天气"}

event: citation
data: {"documentId":"4001","documentName":"橄榄栽培技术规程","chunkId":"4108","page":12}

event: done
data: {"finishReason":"STOP","durationMs":4820}

event: error
data: {"code":50201,"message":"模型服务暂时不可用"}
```

`done` 或 `error` 事件出现后，服务端必须关闭流。

### 7.6 删除会话

```http
DELETE /chat/sessions/{sessionId}
```

仅允许会话所有者或管理员操作。推荐逻辑删除。

## 8. 知识库接口

### 8.1 上传文档（管理员）

```http
POST /knowledge/documents
Content-Type: multipart/form-data
```

表单字段：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| file | File | 是 | PDF、DOCX、TXT、MD |
| title | String | 是 | 资料名称 |
| sourceOrganization | String | 是 | 来源单位 |
| publishDate | Date | 否 | 发布日期 |
| region | String | 否 | 适用地区 |
| phenology | String | 否 | 适用物候期 |
| documentType | String | 是 | 教材、标准、农技资料、校本资料等 |

响应：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "documentId": "4001",
    "status": "PENDING"
  }
}
```

上传成功只代表文件已接收，文档解析和向量化可以异步执行。

### 8.5 删除文档（管理员）

## 13. LangChain4j内部接口

以下内容不是前端 REST 接口，而是后端 Agent 可调用的工具契约。

### 13.1 Agent接口

```java
public interface OliveOrchardAgent {

    TokenStream chat(
        @MemoryId Long sessionId,
        @UserMessage String message
    );
}
```

调用前由应用服务验证 `sessionId` 所属用户，并将果园档案、当前物候期等动态上下文加入系统消息或检索过滤条件。

### 13.2 天气工具

```java
@Tool("查询指定橄榄果园的实时天气和未来天气")
WeatherResult queryOrchardWeather(Long orchardId, Integer forecastDays);
```

### 13.3 果园档案工具

```java
@Tool("读取橄榄果园档案和当前物候期")
OrchardContext getOrchardContext(Long orchardId);
```

### 13.4 计算工具

```java
@Tool("根据株数和单株用水量计算全园灌溉量")
IrrigationResult calculateIrrigation(int treeCount, BigDecimal litersPerTree);

@Tool("根据株数和单株用量计算肥料总量")
FertilizerResult calculateFertilizer(
    int treeCount,
    BigDecimal amountPerTree,
    AmountUnit unit
);

@Tool("根据药液体积和稀释倍数计算原药理论用量")
DilutionResult calculateDilution(
    BigDecimal solutionLiters,
    BigDecimal dilutionRatio
);
```

所有计算使用 `BigDecimal`，明确舍入规则，不使用 `double` 完成最终结果计算。

### 13.5 工具调用约束

- 工具输入必须经过 Bean Validation 或方法内校验。
- Agent 不得直接访问数据库 Repository，只调用受控 Service/Tool。
- 工具返回结构化对象，不返回拼接后的大段自然语言。
- 工具调用输入、结果摘要、状态和耗时写入工具调用日志。
- 同一轮对话限制最大工具调用次数，建议不超过 5 次。

## 14. 模型平台配置

推荐统一采用 OpenAI 兼容接口封装：

```yaml
agent:
  provider: ${LLM_PROVIDER:BAILIAN}
  chat-model: ${LLM_CHAT_MODEL:qwen-plus}
  embedding-model: ${LLM_EMBEDDING_MODEL:text-embedding-v3}
  base-url: ${LLM_BASE_URL}
  api-key: ${LLM_API_KEY}
  timeout-seconds: 60
  temperature: 0.2
```

平台示例：

| 平台 | 用途 | 说明 |
| --- | --- | --- |
| 阿里云百炼 | ChatModel、EmbeddingModel | 可使用兼容 OpenAI 的 API 地址 |
| 硅基流动 | ChatModel、EmbeddingModel | 可选 Qwen、DeepSeek、BGE 等平台已开放模型 |

具体模型名称和地址以比赛开发时平台官方文档为准，不在代码中硬编码。

## 15. 接口测试要求

1. 后端为认证、计算器、果园 CRUD 和权限控制编写单元或集成测试。
